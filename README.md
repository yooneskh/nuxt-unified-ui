# Unified Nuxt UI

A reuseable Nuxt layer which integrates Nuxt UI and some other useful libraries into your Nuxt application.

## Setup

Make sure to install the dependencies:

```bash
vp i
```

## Development Server

Start the development server on http://localhost:8080

```bash
vpr serve
```

## Agent Skills

One installable Agent Skill lives under `skills/nuxt-unified-ui/` (`npx skills` compatible). It covers the layer API **and** mandatory Nuxt code style (forms, dialogs, radashi, formatting).

```bash
npx skills add . --list
npx skills add <owner>/<repo>
```
